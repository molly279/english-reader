从微信 / QQ 收到的 PDF 怎么导入？

微信的文件存在微信自己的空间里，网页读不到，所以要先把它转存到系统「文件」App：

  1. 在微信里打开那个 PDF
  2. 点右上角 「···」
  3. 选 「用其他应用打开」（部分版本叫「打开方式」）
  4. 选 「存储到「文件」」，位置选 「我的 iPad」（选 iCloud 也行）
  5. 回到这里点「导入文献」，在文件选择器里找到它即可

如果没看到「用其他应用打开」，可以先把文件转发给「文件传输助手」，在电脑上打开后再存进网盘 / 邮件附件，iPad 上从网盘或邮件保存到「文件」。

文件在选择器里是灰的、点不动？那是 iOS 选择器禁用了它，不是网页的问题。常见原因是这个文件还在 iCloud 上、没有下载到本机 —— 先打开「文件」App 点一下它，等下载完再回来导入。

Word 文档：新版 .docx 直接就能读，不用转换。老版 .doc 读不了，需要在 WPS / Word 里先「另存为 .docx」或「导出为 PDF」。

图片（截图、拍照、扫描件）：JPG / PNG / WebP / HEIC 都能导入，打开时会自动识别图里的英文，认出来的词就能点（第一次识别要等几秒，之后是秒开）。字太小或太糊会认不出，尽量用原图别压缩。
